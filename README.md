# Artzie NFT Marketplace 🎨

### NFT Marketplace Landing Page | Figma to HTML & Sass (SCSS)

## 📌 Project Overview

Artzie NFT Marketplace is a front-end web development project recreated from a Figma design as part of my Full Stack Development learning journey.

The project focuses on translating a visual design into a web page using HTML5, CSS3, and Sass (SCSS).

The interface features a modern NFT marketplace-inspired layout, a featured artwork gallery, bidding information, custom typography, and decorative graphic elements.

## 🛠️ Technologies Used

- **Figma** – Visual design reference.
- **HTML5** – Web page structure and content.
- **CSS3** – Layout, typography, and visual styling.
- **Sass (SCSS)** – Stylesheet organization and CSS preprocessing.
- **Git & GitHub** – Version control and project management.

## ✨ Features

- NFT marketplace landing page recreated from a Figma design.
- Featured digital artwork gallery.
- Highlighted NFT artwork with bidding information.
- Two-column layout using CSS Grid.
- Custom typography and decorative visual elements.
- Styles developed using Sass (SCSS).

## 🎯 Learning Objectives

- Practice converting Figma designs into HTML and CSS.
- Strengthen CSS Grid and page layout skills.
- Apply Sass (SCSS) in a front-end project.
- Improve visual accuracy when recreating a design.
- Organize project files and stylesheets.
- Practice Git and GitHub workflows.
